# GreatcatNote v0.1.0

First personal release of GreatcatNote, based on Tolaria.

## Highlights

- Renamed app identity to GreatcatNote.
- Added embedded Excalidraw editing using the official Excalidraw React package.
- Added local Excalidraw font assets for the handwritten drawing style.
- Added `.excalidraw`, `.excalidraw.json`, and `.html` file support in the vault.
- Added a New Drawing action for creating `.excalidraw` files directly.
- Added unsaved-change warnings for drawings before switching files or closing the window.

## Artifact

- `GreatcatNote-macOS-aarch64.zip`: macOS Apple Silicon app bundle.
